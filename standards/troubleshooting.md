# 诊断规范（故障定位与排障纪律）

> 目标：**把「听起来像原因」逼成「可复现、可证伪、带证据的原因」**。
> 适用：线上/本机故障、外部依赖失败、行为异常、性能退化。
> 反面案例来源：2026-10-05 dsh-gateway-compaction 压缩失败排障（连续 3 轮错误归因，
> 每轮都是"看起来对"的结论，直到改用对照实验才定位真因）。

## 1. 铁律

| 规则 | 说明 |
|------|------|
| **错误文案不是结论** | 框架/引擎的错误消息常是**通配归类**（把多种真因归为一类）。先读产生该消息的代码，确认它区分了什么、吞掉了什么；再沿 `cause` 链取真因。 |
| **先复现，再改** | 没有最小复现就不动代码。复现脚本、输入样本、命令一并落盘（`docs/04-progress/` 或故障记录），换人可跑。 |
| **一次只动一个变量** | 对照实验必须单变量 + 有基线。**连续快速试错会叠加污染**：若被依赖方对"频率"敏感，连续实验本身就会成为失败原因。 |
| **声明 ≠ 实际** | 第三方/框架对能力的声明（模型是否推理、接口是否支持某字段、窗口多大）可能与真实行为不一致。结论里必须标注**该事实来自声明、实测还是推测**。 |
| **假设必须可证伪** | 写清"什么观察会推翻它"。写不出的不是假设，是信念。至少准备 3 个竞争假设（含 1 个反直觉的）。 |
| **环境拒绝先排除** | 权限/沙箱/杀软/路径 ACL 造成的失败，与产品缺陷表现相同。先用最小写/读探针区分，再怀疑代码。 |
| **隔离修复** | 局部问题的修复**不得污染全局路径**。例：为单个模型关掉某能力，不能改整个 provider 的全局声明（会波及所有普通调用）。优先在调用点收窄，或走配置项。 |
| **降级也要留痕** | 失败被降级/跳过时，必须记录**哪一段、为什么、影响面**，否则等于静默丢数据。 |

## 2. 标准动作序列

1. **固定现象**：时间、命令、输入、错误全文、影响面。区分"每次必现"与"偶发"。
2. **取真因**：读抛出点代码 → 沿 `cause` / 子类 / 日志字段下钻；能拿到结构化错误就别读文案。
3. **列竞争假设**：≥3 个，标注各自**预测的观察**（若 A 成立，应看到…；若 B 成立，则…）。
4. **设计判别实验**：单变量、可重复、单次成本可知；需要冷却/间隔的实验先说明为什么。
5. **取证**：命令原文 + 原始输出 + 时间戳，落到故障记录。禁用"我验证过"式结论。
6. **最小修复**：改在**造成问题的那一层**；能配置化就不写死；能收窄影响面就不动全局默认。
7. **回归**：原有测试 + 针对该真因的新用例（含失败路径）；外部依赖类问题补真机冒烟。
8. **沉淀**：真因 → 本文对应条目；重复出现的检查项 → 落到 `validate/` 或 CI。

## 3. 外部依赖故障（最常踩）

| 现象 | 常见误判 | 正确做法 |
|------|---------|---------|
| 连接被重置（ECONNRESET / fetch TypeError） | "输入太大 / 超窗" | 分别测**单发**（冷却后）与**连续发**；大输入单发能过就说明是**频率/限流**，不是大小 |
| 偶发空输出但 `finish_reason=length` | "模型不会摘要" | 输出预算被**隐藏推理**吃掉；检查是否需要在调用点关闭思考/提高输出上限 |
| 请求被网关拒绝 | "字段写错了" | 用**最小请求**单发该字段（冷却后）；连续发全部失败往往仍是限流，不是字段 |
| 大 body 被拒 | "必须分片" | 同内容**拆成多条小消息**再试；可能是"单条消息无界增长"而非总量 |
| 本地能过、真机失败 | "环境玄学" | 记录两端差异（版本/声明/凭证/网络路径），逐项单变量排除 |

## 4. 交付格式（结论四件套）

- **真因**：一句话，附产生它的代码位置。
- **证据**：可复跑命令 + 原始输出（含失败样本与成功对照）。
- **修复**：改了哪一层、影响面、如何回退。
- **未决**：没验到的部分，明确标"未验证"，禁止用推测填充。

## 5. 验证清单

- [ ] 真因来自 `cause`/代码/实测，不是错误文案的字面意思
- [ ] 有最小复现（脚本/命令落盘，换人可跑）
- [ ] 竞争假设 ≥3 且各写了可证伪条件
- [ ] 对照实验单变量、有时间戳证据
- [ ] 修复限定在造成问题的那一层，未污染全局默认
- [ ] 失败/降级路径有日志或痕迹
- [ ] 针对该真因的回归用例已补
- [ ] 结论四件套（真因/证据/修复/未决）已落盘
