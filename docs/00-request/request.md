目标项目仅为本仓 System1 Ops。工程规范来源见标准快照 `standards/source.json`；不修改 dsh-agent-presets、上游模型源仓库或用户原始权重。目录和质量门禁重构复用已授权的维护、真机测试和公开推送范围。

### 2026-10-12 运维页面状态检查与README

原话：“现在 http://localhost:8885/ 管理密钥输入后, 我有时停掉了决策模型, 或者想要切换某个决策模型时, 页面没有check status工具可用, 增添功能”；“项目readme更新, readme需要写明基本的运维使用方式”。

目标锚定：8885运维台新增按需“状态检查”——对任一决策模型主动探活（进程是否存活、/health健康、是否已加载、端口占用、停止时预检），单模型按钮+“检查全部”，覆盖“已停模型确认”与“切换决策模型前确认目标模型”两个场景；只读端点，无密钥时也可用。README补全基本运维方式：命令行速查、运维台各面板用途、配置位置与修改生效方式。验收：8885真实页面与端点可用，测试与门禁通过。

### 2026-10-12 密钥状态显示与Jev表述纠正

原话见上方用户原话。目标锚定：(1) 运维台头部常驻密钥状态指示（未连接/只读、已连接·密钥有效、密钥无效或已失效），失效时给出明确提示并清空旧密钥便于重输；同时在README/RUNBOOK写明密钥有效期语义。(2) 页面与文档不再把本项目描述为“Jev模型/Jev服务”：统一改为“Jev兼容接口/本地决策模型”，UI、README、RUNBOOK、BRD、SAD、术语表同步纠正；历史阶段报告不改写。验收：页面状态指示可用、401时明确提示，测试与门禁通过。

### 2026-10-12 密钥登录状态跨刷新保持（用户反馈修复）

原话见上方（“我输入密钥后, 刷新了页面然后鉴权都失败了, 你必须经过测试。最好有一个状态显示密钥生效状态”）。目标锚定：(1) 密钥改为保存在当前标签页会话（sessionStorage）：刷新页面保持登录，关闭标签页清除，不写入磁盘/cookie；失效（改密钥/重启运维台）时清除并明确提示重输。(2) 页面右上角常驻密钥状态指示（未连接/只读/已连接·密钥有效/无效失效）。(3) 必须用真实浏览器（Playwright+Chromium）对活动 8885 做端到端验证：无密钥→输入→连接→刷新后仍保持登录→错误密钥→重输恢复，并保留截图/日志证据。
