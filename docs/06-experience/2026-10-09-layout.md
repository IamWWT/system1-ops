# 目录迁移经验

- 源码ROOT从包位置解析工作区；默认私有配置和运行数据不随源码迁移。移动模板后必须同时更新bootstrap和Windows CI。
- 用所选解释器加载同一个包；fallback site-packages只能排在该解释器自身依赖之后，避免CPU torch遮蔽CUDA torch。
- 格式化不是重构行为：单测、真实native、HTTP和Windows流程共同验证，避免只以import成功判定。
- 文档检查只扫描受管文档，排除多GB模型/venv/vendor/cache；引入规范按hash验证，保留来源而不伪造全量适用。
- 覆盖率低要记录，不能通过mock所有模型或删除未覆盖模块来伪造达标。
