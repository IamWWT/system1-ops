# 工程执行协议与验收计划

> 版本: 0.3.0 | 创建: 2026-10-09 | 状态: active
> 关联: [[FILE_INDEX|文件索引]]

## 适用与来源

本协议用于本仓所有工程变更；目标路径锚定于[[00-request/request]]。依据dsh-agent-presets commit74dfcd1270675713853c5f87e798ed9b5f7acb25的engineering persona、project-discipline、engineering-process、obsidian-docs和standards。模式组合配置是DSH宿主加载文件，不在本服务安装DSH插件；工作纪律在本仓独立可执行。

## 开始、变更、交接

先读README、AGENTS、SESSION、request，确认目标/当前未完任务；只把无法从文件发现的用户决策提出。已有用户维护/测试/public推送授权持续有效，不重复请示。用户改需求先登记原话/验收/影响面，再改代码。大迁移先落盘决策完备计划，保留回退映射；本轮为用户要求的同仓组织返工，未迁移父目录独立仓库。

## 七阶段与关口

| 阶段 | 必须内容 | 本仓落点 | 关口验收 |
|---|---|---|---|
| 需求 | 目标路径、原话、假设、目标与差距分离、追踪 | request、BRD、GAP | 用户方向已明确；新增目录行为验收待用户看结果，不能伪造批准 |
| 分析 | 影响面、路线、测试方案 | GAP、SAD、PP、追踪矩阵 | 所有变更能指向实现与验证 |
| 设计 | 候选/取舍、模块契约、文件数据模型 | ADR、SAD、CLM/PMD合并文档 | 不增加中间件；路径规则唯一；旧接口兼容 |
| 开发 | 小批实现、回归、失败记录 | src/native/scripts/tests、04-progress | 包类型/格式/单测和全文引用检查通过 |
| 测试 | 功能与非功能证据 | FTR/NFTR、私有evidence | 真实模型/CPU/Windows与管理边界，未测明确标注 |
| 部署 | 最终用户配置启动、重启/回退演练 | RUNBOOK、DRR、产品归档 | 8882–8885恢复，模型/页面可用 |
| 维护 | 配置管理、基线、交接、经验 | CMP、baselines、SESSION、MEMORY、06-experience | 下个会话可从文件恢复，归档含版本和SHA256 |

关口结论在04-progress追加；不把测试通过当作用户接受。小型组织返工合并分析设计和开发测试，但每类信息保留。

## 本轮实施计划与前提

| 批次 | 操作 | 环境前提 | 验收/失败回退 |
|---|---|---|---|
| L1 | 停四服务、备份配置、迁移.local | PID身份匹配，用户资产可读写 | moves.json可逆；8881保持原状态 |
| L2 | 工具归scripts、单一STATE路径、修引用 | Python3.12、uv锁可用 | 配置所有真实绝对路径不变，模型预检通过 |
| L3 | 全文件索引、交接/基线/数据设计 | 源模式只读，规范快照不改 | 未登记文件、缺交接/基线、根目录杂项会失败 |
| L4 | Linux/Windows门禁、真实native/HTTP/UI | RTX4090已释放、端口未被外部进程占用 | 失败修复记录并重测，不覆盖他人进程 |
| L5 | 唯一main、最新一个标签、产品归档、交付 | 最终检查通过，public仓库既有授权 | 标签固定源码；制品SHA256；回退提交f5eb663及路径映射 |
